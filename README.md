# 🌍 English Overview

<br/>

**Liang Sheng (凉笙)** is a software engineer and computer science undergraduate based in Tianjin, China. His work focuses on systems engineering, algorithm optimization, modern interactive Web development, and deterministic AI agent workflows.

- **Systems & Performance Engineering**: Architected **[Tianke Canteen Planner](https://github.com/liangshengsheng12333/tianke-canteen-planner)**, a client-side multi-constraint meal solver implemented in **C++20** and compiled to **WebAssembly** for WeChat MiniProgram. Re-engineered the dynamic programming algorithm using grid-bucketized states and branch-and-bound pruning, reducing solve latency from **23.46s to 71ms (330x speedup)**.
- **Indie Game Development**: Solo developer of ***STARBREAK: The Final Resonance***, an original sci-fi indie game project currently in private prototype iteration covering gameplay state machines, combat responsiveness, and numerical balance.
- **Creative Web & Interactive UX**: Dedicated to rich interactive experiences beyond conventional enterprise forms. Created **[Jincai Ruhua](https://github.com/liangshengsheng12333/jincai-ruhua)**, implementing an HTML5 Canvas interactive rendering pipeline for traditional Chinese woodblock printing.
- **Applied AI & Agent Toolchains**: Focused on software engineering constraints for LLM stability. Open-sourced **[humanities-writing](https://github.com/liangshengsheng12333/humanities-writing)** (backed by 27 automated integration tests, conservative review scripts, and CNKI/OpenAlex citation lookup), **[Liangsheng Opera House](https://github.com/liangshengsheng12333/liangsheng-theater)**, and **[Liangsheng Workflow](https://github.com/liangshengsheng12333/liangsheng-workflow-friend)**.

Always open to technical discussions and collaboration across systems optimization, game engineering, and robust developer tooling.
