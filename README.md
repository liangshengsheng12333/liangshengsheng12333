# 🇨🇳 嗨，我是凉笙

我平时干的事儿有点杂。本科在写软件工程相关的东西，业余喜欢自己搓独立游戏、做点看着顺眼的交互网站，也重度用 AI 搭工作流。

不太喜欢照着现成框架随便拼个壳子交差，总想顺着自己的好奇心，把一些实际遇到的问题或者脑子里的点子折腾出来。

Hey, I'm **Liang Sheng (凉笙)**, a developer, indie game builder, and creative web maker based in Tianjin, China.

I jump around a few areas that keep me curious:

- **Systems & Performance**: I like getting my hands dirty with **C++20** and **WebAssembly**. For **[Tianke Canteen Planner](https://github.com/liangshengsheng12333/tianke-canteen-planner)**, I squeezed a meal-planning engine into a WeChat MiniProgram via WASM and got the solve time down from 23.46s to 71ms using grid-bucketized dynamic programming.
- **Indie Games**: On the side, I am building ***STARBREAK: The Final Resonance***, an original indie game where I handle everything from story and mechanics to player feel. Still tinkering away in a private repo for now.
- **Creative Web**: I enjoy making interactive sites rather than generic dashboards. In **[Jincai Ruhua](https://github.com/liangshengsheng12333/jincai-ruhua)**, I built an HTML5 Canvas workshop where anyone can try traditional Chinese woodblock printing online.
- **AI Workflows & Skills**: I build practical Agent Skills and scripts to keep AI grounded — like **[humanities-writing](https://github.com/liangshengsheng12333/humanities-writing)** (an evidence-strict writing skill with Python citation tools and 27 tests), **[Liangsheng Opera House](https://github.com/liangshengsheng12333/liangsheng-theater)**, **[Liangsheng Workflow](https://github.com/liangshengsheng12333/liangsheng-workflow-friend)**, and an **[Obsidian Starter](https://github.com/liangshengsheng12333/obsidian-codex-knowledge-base-starter)**.
