# 🇨🇳 你好，我是凉笙 (About Me)

> 我是一名在路上的**软件工程师、独立游戏开发者与独立网站创作者**，也是 AI 深度工作流与 Agent Skill 的构建者。  
> 对我而言，写代码从来不是堆砌专业名词，而是**把脑子里的奇思妙想变成真实跑在屏幕上的作品**——无论是能帮同学省钱吃好饭的小程序、一把手感扎实的游戏原型、让人眼前一亮的交互网页，还是真正靠谱可控的 AI 工具链。

Hi there! I'm **Liang Sheng (凉笙)** — a **Software Engineer**, **Indie Game Developer**, **Creative Web Builder**, and **AI Skill Creator** based in Tianjin, China.

In **[Tianke Canteen Planner](https://github.com/liangshengsheng12333/tianke-canteen-planner)**, I built a C++20 meal optimization solver compiled to WebAssembly for WeChat MiniProgram, cutting computation latency from **23.46s down to 71ms (330x faster)** with grid-bucketized Dynamic Programming and Branch & Bound.
