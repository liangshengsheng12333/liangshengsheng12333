# 🇨🇳 见字如面 · 关于凉笙

> 坐标津门，在读计算机学子，日常以 **C++、Python 与前端**为笔墨，课余独自酝酿**独立游戏**，也写了几套令大模型守规行事的 **Agent Skills**。  
> 写程序最动人之处，在于将转瞬即逝的灵感化为屏幕上实实在在的器物：底层求一份精准克制，交互之间，也愿多留三分温度与雅趣。

# 🌍 English Intro

<details open>
<summary><b>Read in English</b></summary>

<br/>

I'm **Liang Sheng (凉笙)**, a CS undergraduate and builder in Tianjin, China. I spend most of my hours with **C++, Python, and TypeScript**, crafting a solo indie game on the side and building deterministic **Agent Skills** for LLM workflows.

- **Systems & Performance**: In **[tianke-canteen-planner](https://github.com/liangshengsheng12333/tianke-canteen-planner)**, wanting zero server overhead for campus meal planning, I wrote a **C++20** solver compiled to **WebAssembly** inside a WeChat MiniProgram. Reworking the dynamic programming table with grid bucketing and pruning cut latency from ~23s to 71ms.
- **Indie Game Craft**: Beyond utility code, I am creating ***STARBREAK: The Final Resonance*** in a private repository, refining worldbuilding, mechanics, and game feel solo at an unhurried pace.
- **Interactive Web**: Rather than building repetitive CRUD dashboards, I enjoy bringing visual heritage onto the browser. **[jincai-ruhua](https://github.com/liangshengsheng12333/jincai-ruhua)** turns traditional Yangliuqing woodblock printmaking into a four-step HTML5 Canvas workshop.
- **Grounded AI Tooling**: Instead of relying on fragile ad-hoc prompting, I anchor LLM workflows with explicit constraints and Python tools in **[humanities-writing](https://github.com/liangshengsheng12333/humanities-writing)** (27 tests + CNKI/OpenAlex verification), **[liangsheng-theater](https://github.com/liangshengsheng12333/liangsheng-theater)**, **[liangsheng-workflow](https://github.com/liangshengsheng12333/liangsheng-workflow-friend)**, and an **[Obsidian starter](https://github.com/liangshengsheng12333/obsidian-codex-knowledge-base-starter)**.

Always glad to trade notes on systems engineering, indie games, or practical AI tooling. Feel free to say hello!
